# carefit-midia

Artes públicas da CareFit Run Base usadas pelo agendador (Buffer) para publicar no Instagram, Facebook e TikTok.
O Buffer só aceita imagem por link público; este repositório serve esses links
(`https://raw.githubusercontent.com/Gu1306/carefit-midia/main/...`).

**Regra:** só arte de marca que já vai ser publicada. Nunca foto de atleta, documento, dado pessoal ou de saúde.

- `series/AAAA-MM-DD/carefit-NN.png` — carrosséis das séries (domingo, Lista, Perguntas), na data do post.
- Fonte das artes: `C:\Projetos\carefit-carrosseis\` (domingo/ e quarta/).
